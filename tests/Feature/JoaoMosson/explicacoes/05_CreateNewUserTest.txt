O QUE ESTE TESTE VERIFICA
------------------------------------------------------------------------------
* Testa se o cadastro com e-mail de um domínio que nenhuma organização possui é bloqueado, com a mensagem "O domínio do seu e-mail não está cadastrado com nenhuma organização parceira.", e se o usuário não é gravado.
* Testa se o cadastro com e-mail de um domínio de organização existente cria o usuário como PADRAO, vinculado a essa organização.
* Testa se, nesse cadastro, a carteira do usuário também é criada.

CÓDIGO:
    use App\Actions\Fortify\CreateNewUser;
EXPLICAÇÃO:
    A classe testada: app/Actions/Fortify/CreateNewUser.php.
    Uma "Action" é uma classe com UMA responsabilidade; esta cadastra um usuário comum. O método create($dados) faz,
    em ordem:
    1) valida os dados (nome, e-mail único, senha, CPF válido e único);
    2) pega o domínio do e-mail (o que vem depois do "@");
    3) procura uma Organizacao cujo "dominio_email" seja igual a esse domínio;
    4) se não achar, lança uma ValidationException (erro de validação);
    5) se achar, cria o User já ligado a essa organização, com tipo PADRAO e senha criptografada;
    6) cria a Carteira do usuário e o devolve.
