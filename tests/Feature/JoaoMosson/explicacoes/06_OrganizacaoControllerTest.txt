CÓDIGO:
        public function test_atualiza_o_nome_da_organizacao_com_sucesso(): void
        {
EXPLICAÇÃO:
    CASO 2: o administrador consegue renomear uma organização.

------------------------------------------------------------------------------

CÓDIGO:
            $org = Organizacao::create([
                'nome' => 'Antigo Nome',
                'cnpj' => '11444777000161',
                'dominio_email' => 'antigo.com',
            ]);
EXPLICAÇÃO:
    ---------- ARRANGE ----------
    Organização com um nome antigo, que será substituído.

------------------------------------------------------------------------------

CÓDIGO:
            $response = $this->actingAs($this->admin)
                ->from(route('admin.organizacoes'))
                ->put(route('organizacoes.alterar', $org), [
                    'nome' => 'Novo Nome Atualizado',
                ]);
EXPLICAÇÃO:
    ---------- ACT ----------
    Logado como administrador. O encadeamento é lido assim:
    ->from(...): define a página "de onde a pessoa veio". O controller termina com back(), que redireciona
    para a página anterior. Em teste não há navegador nem histórico, então precisamos informar
    esta página; sem o from(), o back() não saberia para onde voltar.
    ->put(url, dados): faz uma requisição HTTP PUT (usada para atualizar). route('organizacoes.alterar', $org)
    gera a URL passando a organização; o Laravel usa o id dela na URL e, no controller, devolve
    o objeto Organizacao correspondente (isso se chama "route model binding").
    O array é o corpo do formulário: o campo "nome" com o novo valor.

------------------------------------------------------------------------------

CÓDIGO:
            $response->assertSessionHasNoErrors();
EXPLICAÇÃO:
    ---------- ASSERT ----------
    A validação ('nome' => 'required|string|max:255') passou: não há mensagens de erro na sessão.

------------------------------------------------------------------------------

CÓDIGO:
            $response->assertRedirect(route('admin.organizacoes'));
EXPLICAÇÃO:
    Resposta é um redirecionamento de volta para a listagem (o efeito do back()).

------------------------------------------------------------------------------

CÓDIGO:
            $this->assertDatabaseHas('organizacoes', [
                'id' => $org->id,
                'nome' => 'Novo Nome Atualizado',
            ]);
        }
    }
EXPLICAÇÃO:
    Prova mais importante: no BANCO, a linha com o id desta organização agora tem o nome novo.
    Conferir só o redirecionamento não bastaria, pois ele ocorre mesmo que a atualização não tenha gravado nada.
